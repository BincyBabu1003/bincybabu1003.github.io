🔍 Retrieval-Augmented Generation (RAG) Chatbot — LLM Application (Python, LangChain, Vector DB)

Personal Project

Developed a Retrieval-Augmented Generation (RAG) chatbot that combines Large Language Models with semantic search to provide context-aware and accurate responses from custom documents.

Built a full pipeline including text embedding generation, vector database storage (FAISS), and retrieval of top-k relevant chunks before passing context to an LLM for response generation.

Integrated prompt engineering techniques to improve response relevance and reduce hallucination compared to standard LLM chatbots.

Designed and tested different retrieval strategies and evaluated response quality based on contextual accuracy.

Summary: “I built a chatbot that retrieves relevant knowledge from documents and then uses an AI model to generate accurate, context-aware answers.”
